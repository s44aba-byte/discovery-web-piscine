# Discovery Web Piscine - Project 00
## Overview
This is my first project in the 42 Discovery Web Piscine. It covers the basics of the Linux terminal, navigating without a GUI, managing files using shell commands, and setting up Git and GitHub for tracking code.
## Why Git Makes Development Easier
- - **Saves code history:** I can track every change I make and easily go back to an older working version if something breaks.
- **Clear logs:** The commit history shows what was changed, when, and why, which makes debugging much easier.
- **Teamwork:** It allows multiple people to work on the same project at the same time using GitHub, avoiding code loss and conflicts.
